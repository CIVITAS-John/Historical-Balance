# USU and CPC Trade Centers

Use this add-on only when your playset has both **Grey's Urban Synergy Unleashed** and **Controllable Private Construction**. Copy this folder beside `fictional-history` in your Victoria 3 `mod` directory, then enable **Tungning: USU and CPC Trade Centers** in the same playset.

The add-on restores Grey's port status group to trade centers worldwide and keeps CPC's construction rules for that building. All four trade quantities use Grey's original costs.
